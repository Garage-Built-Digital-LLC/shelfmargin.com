# ShelfMargin Asset System

Current visual direction: Reseller Notebook.

This folder tracks the next visual system after the rejected generated assets were removed.

- `brand-profile.md`: visual rules, palette, typography, and image style.
- `project-intake.md`: app context and target pages.
- `asset-audit.md`: where assets are needed in the current app.
- `asset-manifest.json`: asset IDs, filenames, paths, status, and intended usage.
- `prompt-pack.md`: copy-ready image-generator prompts.
- `implementation-plan.md`: how to wire generated assets after approval.
- `visual-concepts.md`: concept exploration notes.
- `visual-concepts/`: generated concept-board reference images.

Do not add runtime references to generated media until the final files exist under `public/assets`.
