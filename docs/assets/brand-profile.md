# ShelfMargin Brand Profile

## Direction

ShelfMargin is moving to the Reseller Notebook visual system: a scanner-first used-book sourcing app that feels like a clean field notebook, barcode scanner, and buy-list worksheet.

The look should be practical, organized, and professional. Handwritten details can appear in supporting visuals, but product UI and marketing copy should remain clear, readable, and modern.

## Brand Traits

- Scanner-first
- Field-ready
- Reseller practical
- Organized notebook
- Clear profit decisions
- Trustworthy but not corporate

## Color Palette

| Role | Hex | Usage |
|---|---:|---|
| Notebook paper | `#F7F2E8` | Page backgrounds, hero paper surfaces |
| Clean white | `#FFFFFF` | App panels and phone screens |
| Ink black | `#171717` | Primary text, barcode marks, linework |
| Denim blue | `#1F5A7A` | Primary actions, links, trust accents |
| Highlighter yellow | `#F4D35E` | Scan beam, highlighted notes, active state |
| Profit green | `#2E7D50` | BUY state and positive profit |
| Check amber | `#C98224` | CHECK state and caution |
| Pass red | `#C24132` | PASS state and negative decisions |
| Paper line | `#D8CFBC` | Ruled lines, borders, notebook dividers |
| Muted graphite | `#5E625F` | Secondary text and metadata |

## Typography Direction

- Use strong readable sans-serif for app UI, nav, headings, and buttons.
- Use handwritten-style marks only for supporting art, notebook labels, and checklist accents.
- Do not bake long UI text into generated images.
- If text is required in an image, keep it short and large.

## Visual Motifs

- Ruled notebook paper
- Margin lines
- Checklists
- Highlighter strokes
- Barcode stickers
- ISBN labels
- Book spines and used-book stacks
- Scanner beam
- Phone scanner UI
- CSV/list export cues

## Global Negative Prompt

No generic SaaS gradient, no purple/blue startup blobs, no fake marketplace logos, no Amazon/eBay logos, no guaranteed profit claims, no tiny unreadable UI text, no messy collage, no cartoon mascot, no childish notebook doodles, no cluttered full-frame background, no unrealistic glossy device reflections, no fake app store badges.
